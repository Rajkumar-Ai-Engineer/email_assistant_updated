# Calendar Privacy

## When to use
- When scheduling with external contacts or unknown senders.
- When proposing calendar conflicts or free times to recipients outside the company.
- When internal colleagues request calendar details about other people's events.
- To decide what information may be shared and what must be hidden.

## Core rules
- The calendar agent returns times only, never titles or attendees, to anyone outside.
- External or unknown contacts learn only "a conflict" or "another commitment", no details.
- Internal colleagues learn nothing by default unless the user grants explicit permission.
- Never expose one contact's information to another.
- Acceptable phrasing: "I have another commitment", "There is a conflict", "That time does not work."
- Forbidden phrasing: event titles, attendee names, project names, meeting purpose.

## Files
- `instructions.md`: read first; the privacy rules and how to phrase responses.
- `reference.md`: consult for the audience table and acceptable vs. forbidden phrases.
- `example.md`: open to see examples of private vs. public scheduling responses.
